Project Overview

ForoPlatos is a full-stack monolithic web application built entirely with vanilla PHP and SQL, designed as a community-driven recipe forum. The platform allows users to register, log in, create discussion threads about recipes and dishes, post replies, and manage their profiles — all through a server-rendered interface without relying on any framework.

The project demonstrates strong fundamentals in web development by handling the full request lifecycle manually: from routing and form validation to session management, SQL query execution, and HTML rendering. It showcases the ability to build a complete, functional web application from scratch while maintaining organized code structure and secure data handling practices.

Key Technical Features

Authentication & Sessions

Complete user registration and login system with PHP sessions, password hashing, and access control to protect restricted routes and actions.

Raw SQL & Database Design

Direct interaction with MySQL/MariaDB using prepared statements and parameterized queries, with a normalized relational schema for users, threads, and replies.

Full CRUD Forum System

Users can create, read, update, and delete discussion threads and comments. The forum supports threaded replies and pagination for a complete community experience.

Monolithic MVC Structure

Clean separation of concerns following an MVC-inspired pattern within a monolithic PHP architecture, keeping views, logic, and data access organized and maintainable.
